# Oyster360 - User Guide

This guide explains how to use Oyster360 for daily oyster mushroom farm operations.

## Getting Started

### Login

1. Go to the Oyster360 login page
2. Enter your email and password
3. Click **Sign In**

## Main Features

### 1. Dashboard

The dashboard gives you an overview of your farm:

- **Active Batches**: Number of batches currently growing
- **Expected Harvest**: Total expected production this month
- **Success Rate**: Percentage of successful batches
- **Average Yield**: Average yield per batch

**Current Production Status** shows:
- Colonization stage bags
- Fruiting stage bags
- Batches ready for harvest

---

### 2. Batches

**View All Batches**
- Go to **Batches** from the sidebar
- Search, sort, and filter batches
- Export data as CSV

**Create a New Batch**
1. Click **Create Batch**
2. Fill in:
   - Batch Number
   - Strain
   - Room
   - Recipe Version
3. Click **Create Batch**

**View Batch Details**
- Click on any batch number
- See timeline, growth logs, environmental data, and AI insights

---

### 3. Recipes

**View Recipes**
- Go to **Recipes**
- See all substrate recipes with success rates

**Create New Recipe Version**
1. Go to a recipe
2. Click **New Version**
3. Enter new hydration and spawn ratio
4. Add notes
5. Save

---

### 4. AI Assistant

**Ask Questions**
1. Go to **AI Assistant**
2. Type your question, for example:
   - "Why is Batch OY-2026-012 growing slowly?"
   - "Which recipe has the highest yield?"
   - "When should I harvest Batch OY-2026-015?"

3. Click **Send**

The AI will analyze your farm data and provide recommendations.

---

### 5. Image Analysis

**Upload Mushroom Images**
1. Go to **Image Analysis**
2. Enter Batch ID
3. Paste image URL or upload image
4. Click **Analyze with AI**

**Results Include**:
- Health Score
- Growth Stage
- Contamination Risk
- Recommendations

---

### 6. Inventory

**View Stock**
- Go to **Inventory**
- See current stock levels
- Low stock items are highlighted

**Record Stock Movement**
1. Select an item
2. Choose transaction type (IN/OUT)
3. Enter quantity
4. Add notes
5. Save

---

### 7. Analytics

**View Performance**
- Go to **Analytics**
- See:
  - Strain performance
  - Recipe performance
  - Environmental trends
  - Yield predictions

---

## Worker Features

### Worker Dashboard

Workers can access a simplified dashboard showing:
- Today's tasks
- Assigned batches
- Alerts

### Daily Workflow

1. Check assigned rooms
2. Record environmental data
3. Add growth logs
4. Upload inspection images
5. Report issues

---

## Best Practices

### Daily Tasks
- Record environmental data twice a day
- Add growth logs every 2-3 days
- Upload inspection images when issues appear

### Weekly Tasks
- Review AI recommendations
- Check inventory levels
- Analyze batch performance

### Monthly Tasks
- Review analytics
- Compare recipe performance
- Plan next month's production

---

## Getting Help

- Use the **AI Assistant** for cultivation questions
- Contact your farm manager for account issues
- Check the **Analytics** page for performance insights
