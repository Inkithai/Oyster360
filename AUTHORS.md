# Authors

Oyster360 is written and maintained by one person, with assistance from
automated tooling. The GitHub contributor graph is the source of truth.

## Maintainer

- **Inkithai Meiyalagan** ([@Inkithai](https://github.com/Inkithai)) — sole
  author and maintainer: backend platform, multi-tenancy, frontend, CI, and
  releases.

## Automated contributors

These accounts appear in the commit history and are tooling, not people:

- `arena-ai-coding-agent[bot]` / `Arena Agent` — AI coding agent used for
  test coverage, CI hardening, and refactoring work.
- `dependabot[bot]` — automated dependency updates.
- `github-actions[bot]` — lockfile regeneration on Dependabot pull requests.

## A note on the commit history

Earlier revisions of this file listed ten named maintainers. Those names were
not real contributors and have been removed. See
[Repository history and provenance](README.md#repository-history-and-provenance)
in the README for a full account of what the commit history does and does not
represent.

## How to be listed

Land a merged pull request that includes tests (see
[CONTRIBUTING.md](CONTRIBUTING.md)), then add yourself in the same pull
request. Names are added only for genuine, attributable contributions.
