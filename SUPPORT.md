# Support

Oyster360 is an open development project for commercial oyster mushroom farm operations.

## How to get help

1. Read [README.md](README.md) and [docs/SETUP.md](docs/SETUP.md) for install, run, and test instructions.
2. Search [existing issues](https://github.com/Inkithai/Oyster360/issues) to see if your question is already answered.
3. Open a new issue with the bug or question template. Include OS, Docker/Node/Python versions, and the exact command that failed.

## What to include in a bug report

- The command you ran (`make bootstrap`, `npm test`, `pytest`, …)
- Full error output
- Whether you followed only the README from a fresh clone
- A minimal reproduction if the bug is in an API route or page

## Security issues

Do not file public issues for vulnerabilities. See [SECURITY.md](SECURITY.md).

## Commercial / farm onboarding questions

Describe your farm size, number of rooms, and whether you need billing (Stripe) or the rule-based AI assistant only. A maintainer will point you at the right module.
